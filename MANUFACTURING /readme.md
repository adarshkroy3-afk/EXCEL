# 🏭 Manufacturing & Predictive Maintenance Analytics

## 📌 Project Overview

This project focuses on analyzing **manufacturing machine data** to identify machine failures, failure patterns, and factors that may affect machine performance.

The project uses **Microsoft Excel** for data analysis, Pivot Tables, Pivot Charts, and an interactive dashboard.

## 🎯 Objectives

* Analyze machine performance and operational data.
* Identify the number of machine failures.
* Analyze machine status by machine type.
* Identify different types of machine failures.
* Understand factors related to machine failures.
* Create an interactive dashboard for easy visualization and decision-making.

## 📊 Dataset

The dataset contains **10,000 records** of manufacturing machine information.

Some of the important fields include:

* Machine Type
* Machine Status
* Failure Type
* Tool Wear
* Air Temperature
* Process Temperature
* Rotational Speed
* Torque
* Operational Data

## 🔍 Key Analysis

The project analyzes:

### Machine Status

The dataset contains two main machine statuses:

* **Normal**
* **Failure**

There are **339 failure records** and **9,661 normal records** out of 10,000 records.

### Machine Type

Machine performance is analyzed across different machine types:

* Type H
* Type L
* Type M

The analysis helps identify which machine types have a higher number of failures.

### Failure Analysis

Failure types are analyzed to understand the major reasons behind machine failures and identify areas that may require maintenance.

## 💡 Key Insights

* Most machines in the dataset operate under normal conditions.
* A smaller portion of machines experience failures.
* Machine failure rates differ between machine types.
* Failure analysis can help identify machines that require preventive maintenance.
* Operational parameters such as tool wear and machine conditions can be useful for monitoring machine performance.
